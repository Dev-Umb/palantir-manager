使用说明

本版本为本机离线工作台，双击打开即可使用，推荐使用 Windows 的 Edge 或 Chrome。三个进度模块支持行内单选模板进度和发货情况、其他字段直接编辑，点击“保存修改”后保存，关闭网页有未保存改动时提示、自动分组、Excel导入导出。原材和进度共用完整工程备份。表头、项目名称和保存区域固定；“查看未保存”支持定位和放弃修改。一批修改校验通过后统一保存，出错时保留整批输入。导出、打印或备份遇到未保存修改时，可选择“保存后继续”。

数据保存在当前浏览器。在线版也不提供云端同步。移动 HTM、换电脑、换浏览器或清理浏览器前，点击“保存工程备份”，在新位置“恢复工程备份”。单独复制 HTM 不包含后来新增的记录。

顶部“多选月份”支持不连续月份与跨年选择，勾选后点击“应用选择”；单月输入框用于快速切换单月，“全部月份”恢复全部时间。多月筛选可与型材/板材等其他条件一起使用，导出和打印范围同步更新。月份与其他筛选会在本浏览器记住，重新打开自动恢复；顶部条件标签可逐项取消，“重置全部筛选”恢复全部正常记录。回收站状态不记忆。

原表历史记录只在第一次打开时导入。快捷录入按到货日期归月，重量单位为吨。每车可以有多个材料和规格。槽钢、工字钢自动归为型材，中板、开平板自动归为板材；其他材料可在录入时手动选择大类。同车槽钢与工字钢合计为型材，重量只计一次。跨大类混装无分项重量时单列，旧数据中无法自动识别的材料显示待分类。

Excel 导入支持原表及本工作台导出的 15 列“进场统计”工作表。导出的“材料大类”附表用于保留手动分类，重新导入时请一并保留。同一文件和相同记录跳过；同日同车而内容不同的记录会阻止整次导入，需先核对原表。

“导出当前报表”和打印采用当前期间及筛选；完整工程 JSON 包含原材及三个进度模块的全部正式记录、回收站和导入历史，不包含尚未提交的录入草稿。

草稿随本浏览器保存；提交失败会保留输入。台账删除后可在回收站恢复；回收站内不导出或打印正常报表。最近备份导出时间会保留，有后续变更时提醒重新导出；提示不代表浏览器已完成下载，请确认 JSON 文件已保存。恢复工程前保留原工程，支持撤销上次恢复。

报表沿用原表的灰色表头、小计、浅黄色总计和一车多项合并格式。打印请选择 A4 横向，并关闭浏览器附加的页眉页脚。

三个进度表的发货重量为项目累计数，日期是最后一批发货日期。按最后发货月份筛选时，展示的是所选项目累计重量，不能作为当月实际发货量。智能部分单独统计，不计入发货吨位。
