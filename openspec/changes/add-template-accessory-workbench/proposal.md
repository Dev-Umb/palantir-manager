# 独立模板与配件工作台

## Why
用户要求按最新完整包拆出独立模板与配件工作台，并导入之前提供的三份 Excel；两个工作台均快速返回平台。用户已授权开发和线上导入，沿用先合并后部署流程。

## What Changes
- 按最新离线 demo 提取台车模板、开挖台架、液压配件 UI 与计算、导入导出规则。
- 独立入口、权限、数据库；共享正式记录与恢复快照，个人草稿及筛选按账号存数据库。
- 保留行内编辑、批量保存、草稿续编、筛选、分组小计、回收站、打印、导入预览与选择更新。
- 两工作台返回平台，原材业务不变；不自动装入 demo 内历史数据。

## Impact
独立加法迁移、控制器、校验、服务和原版前端资源；不增加依赖。
