## Why

业务项目目前只对负责业务员、财务和管理员可见，无法让另一名业务员在不取得编辑权的前提下了解指定项目。项目负责人和管理员需要一个明确的“知会人员”入口，让被知会业务员只读查看该项目，并在列表中识别这是知会项目。

## What Changes

- 在业务项目新增可多选的“知会人员”字段，候选人仅包含业务员账号。
- 项目负责业务员和管理员可以维护知会人员；财务及被知会业务员不能维护该字段。
- 被知会业务员可以查看被指定的项目，但对该项目保持完全只读。
- 被知会业务员看到项目列表时，该记录显示“知会项目”提示标记。
- 保持原项目负责人、财务、管理员的既有可见性和字段权限。
- 知会可见性不扩展到合同记录，也不改变项目到期提醒接收人。

## Capabilities

### New Capabilities

- `project-informed-viewers`: 管理项目知会人员、只读可见范围和知会标记。

### Modified Capabilities

- None.

## Impact

- 项目元数据增加一个 JSON 数组字段，不新增数据库表或物理列。
- 项目查询增加对知会人员账号 ID 的 JSON 包含判断。
- 项目更新授权增加记录级所有者判断，防止被知会业务员通过接口修改项目。
- 项目列表和详情数据增加当前用户的记录级只读/知会标识。
- React 表格和编辑弹窗根据记录级权限关闭编辑入口并显示提示。
