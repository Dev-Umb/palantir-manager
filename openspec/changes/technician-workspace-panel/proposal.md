# 技术员主面板

## Why
技术员从登录页登录默认进入主面板时返回 403。用户明确要求账号可以进入基本主面板，但只展示原材进场和模板与配件两个工作台。

## What Changes
- workbench_technician 角色可进入首页、主面板和可视化首页路径，均展示同一简洁工作台入口页。
- 面板只展示获授权的两个工作台，不查询或返回经营驾驶舱数据；导航保留主面板、两个工作台和账号设置。
- 保留其他角色面板和权限语义，技术员不获得 dashboard.view 或其他业务权限。

## Impact
角色识别、面板路由权限、两个面板控制器、共享导航、一个 React 页面及回归测试。无数据库结构变更。
