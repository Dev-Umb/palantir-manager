# 设计

沿用现有共享支架库的单共享库模式，用数据库JSON保留原dataset结构与精度，不另建材料/供应商主数据。共享状态单行含revision、dataset、恢复前快照；个人持久状态按user_id和key唯一，版本保护；幂等回执按user_id与request_id唯一。

正式写入通过明确save/delete/import/restore/undo命令，后端重新校验并在锁定当前数据的事务内计算；不开放客户端任意覆盖dataset的普通保存接口。恢复/撤销另需recover权限。草稿/筛选/备份提示只更新当前用户的一项，不接受user_id。

原demo的DOM、CSS、Excel库、业务计算及渲染保留，删除内嵌历史种子和IndexedDB适配，用数据库请求替代。草稿保存成功提示必须等待请求成功，保存失败保留输入。无localStorage或IndexedDB业务持久化。网络状态不明时复用请求ID重试，服务端幂等回执保障不重复写入。

Inertia页只提供全屏同源工作台容器，工作台文档由平台鉴权返回，使用会话CSRF及同源CSP。不用平台样式重画demo。平台原有专用账号限制保持。

上线数据为空，不自动导入交付包历史数据。复刻基线仅用于隔离测试；旧JSON通过原恢复入口进入数据库。
