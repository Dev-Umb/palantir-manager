## 写入及读取
仅在保留对象的 Eloquent save 边界执行事务和既有 ReferenceGraphLock；废弃对象直接保持原 save 行为。源记录名称/编号改变时，仅同步保留对象中的明确关联快照；只规范化关联名称和合同项目编号。HTTP、项目合同维护、客户资料联动和 AI 的实例写入均覆盖。批量 SQL 不触发模型行为；读取当前名称和显式维护命令提供补救。

搜索在既有授权过滤内按当前关联 ID 查询主档名称。保留对象在列表、详情、导出优先读取有效主档名称；无效引用只保留快照线索，不猜测替换。旧模块继续原快照行为。
