# Design

保留 Inertia React 入口和所有页面，先提供必要的标准 API，再执行依赖模块。降低构建语法目标不会补充运行时 API，也不保证 Tailwind v4 在旧浏览器完整兼容；只补充验证发现的阻塞点及基础交互样式，不降级框架或替换页面。

验证缺失 API 的失败/恢复、原生实现保留、启动失败可见/成功清理，以及构建和业务邻接回归。真实 Chrome 86 或用户 360 验收是独立证据；伪造 User-Agent 不能证明兼容。

回滚仅涉及本轮入口、兼容模块、样式与构建配置，不改数据库。生产构建需以线上实际源码为基线，不能把 APP 或历史脏改随兼容修复上线。
