# 删除已废弃的旧业务运行代码

用户授权在名称同步部署后清理废弃代码，以线上 BusinessWorkspace 保留对象和当前导航为依据。
必须改变：移除废弃对象配置、采购申请/现场报工入口及专用控制器页面、材料参考数据自动种子、图纸班组材料及库存的专用写入分支。
必须保持：客户、联系人、招投标、项目、业务概括、合同，以及经营大盘、AI、参考报价、招采中心、工日簿、附件、权限、通知和历史归档。
允许隐藏：已废弃入口不恢复；必须可见：现用入口保持。
禁止推断：工日簿账号人员和参考报价材料参数仍在使用，不属于废弃业务对象。
现有历史数据不删除。元数据更新应保留移除对象的归档记录，不能级联删除业务记录。
