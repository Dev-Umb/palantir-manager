# Design

用关联用户名称补充项目姓名查询，并与原搜索 OR 条件同组，保留外层权限和筛选。合同排序用受限项目关联子查询，不使用导致分页重复或丢失孤立合同的内连接，不新增持久字段。保留项目默认排序完整稳定键，同项目多合同相邻。

名称标签仍返回原 ID、code、title，仅 label 删除重复前缀；其他对象格式不变。独立项目编号列保留，远程关联搜索继续匹配编号。项目切换选项文本只显示名称。

以线上真实控制器为基线；当前完整隔离目录保留未发布附件删除修改，因此不能整目录上线。测试涵盖姓名/编号搜索、筛选及权限交集、多合同、同顺序值、未排序和失效关联、分页、手动排序、CSV和名称编号保留。生产数据库不改。
