# 修复业务员搜索、合同顺序与项目名称

## Why
项目保存业务员账号 ID，通用搜索只匹配原始数据，姓名搜索缺失；合同默认按自身更新时间，不能跟随项目默认顺序；项目名称标签重复前缀编号。

## What Changes
- 项目及其现有业务汇总表按负责业务员当前显示姓名搜索，合同保留已有项目业务员姓名搜索。
- 合同默认按所属项目的完整默认顺序排列：对账单隐藏顺序、空顺序置后、项目更新时间及 ID；同项目合同保持自身更新时间和 ID 稳定排序，无有效项目的合同放最后但不丢弃。
- 项目名称标签和项目切换选项仅显示名称，独立编号字段、关联 ID、搜索编号与其他对象标签保留。

## Scope Contract
必须改变：上述三项浏览行为。必须保持：权限、过滤、分页、手动排序、导出、金额、记录及独立编号字段。允许隐藏：名称前重复编号。必须可见：姓名搜索结果、完整合同、名称和独立编号。禁止推断：项目没有合同就新增合同、以合同日期代替项目顺序、同名就合并记录。

## Review
用户明确提出三项修复，本方案按最小范围执行本地实现与验证。新生产发布需独立核对和授权，不沿用此前仅限启动兼容两文件的发布授权。
