## Why
小程序新建项目只能选择已有客户，用户要求对齐 Web：直接输入客户名称，不存在时随项目自动创建。
## What Changes
- 仅新建项目且服务端 can.manage_customers 为真时增加客户直接填写，保留选择已有客户与联系人。
- 复用 Web customer_profile、预检接口和项目原子提交；名称和地址组合复用，不在客户端另建客户。
- 直接填写包含名称、地址、等级、性质及可选联系人姓名/电话；已有客户选择仍走原关系字段，不隐式修改主档。
- 预检发现共享资料差异时列出旧值/新值，明确确认才覆盖；取消保留草稿。
- 用户已要求开发并部署，并补充本需求；复用 inline-project-customer-profile 既有业务规范，无后端规则变更。
## Impact
- mobile/wechat/pages/edit 及相关 Node 测试。
- 保留项目编辑、现有客户选择/联系人、所有其他字段及权限。无 schema 或依赖变更。

## Approved correction — 2026-11-14
用户明确要求客户创建在二级页面，项目创建保持原状。撤销项目主表单内客户名称/地址/等级/性质/联系人展开字段；在原客户选择页内提供二级客户表单入口。填写结果带回原项目客户栏，仍在项目提交时使用既有原子创建/复用流程。独立客户列表新增入口保持即时保存行为。
