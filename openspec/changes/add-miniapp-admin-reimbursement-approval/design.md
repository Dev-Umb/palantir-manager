## Decisions
复用现有小程序和报销详情，不建立独立管理员端。角色来自 MiniappSessionController 返回的 roles，不提供身份切换或客户端自授权限。管理员入口可见性不替代服务端审批授权，也不收紧现有 PC 非管理员被指派审批人的权限。

快速审批路径：工作台“OA 审批” → 当前待办 → 报销详情 → 通过确认或输入驳回原因 → 提交 → 刷新详情及待办。不增加批量审批，未收到成功响应不提前显示成功。驳回原因必填，长度沿用后端限制。

现有 scope=review 包含所有被指派版本，status=pending 也可能包含未来节点或本人已投票的会签节点，因此不能直接当作当前待办。实现时增加独立服务端当前待办筛选，按最新版本、当前节点、尚未处理、参与人有效等条件过滤后再分页；列表总数必须与可处理集合一致。复用或严格对齐 canDecide，不能只在当前页客户端过滤。保持既有 review/pending_count 语义。

提交沿用 POST /reimbursements/versions/{version}/decision，传原详情 node_index、decision、note；身份由会话确定。保留锁、重复投票限制及过期节点 409。提交期间禁用重复操作；失败保留意见；超时提示结果待确认并重新查询，禁止自动重提。403/409 刷新权限和状态，不显示虚假成功。登出、切换账号和角色变化清除旧待办及按钮，迟到响应不能恢复旧身份状态。

## Alternatives and risks
不建立第二套审批服务，避免流程和审计分叉；不把管理员身份当作全局审批权限。工作区存在大量其他未提交改动，本任务只处理新提案，实施时须隔离审阅范围。基础报销和小程序代码是否已合并、上线需独立核实。

## Rollout and rollback
无需数据迁移；可通过回退新增入口和页面操作关闭小程序审批，不回滚已提交审批记录。测试、质量门禁、PR 合并、服务部署、小程序体验版及真机验收分开记录。真实审批会改变线上数据，验收使用专门授权单据；详情 GET 当前会标记通知已读，不能作为无副作用的只读验收。

## Specification dependency and validation
本提案依赖 add-reimbursement-oa 中的同名能力；基础变更尚未归档到 openspec/specs，因此 MODIFIED delta 目前会出现“target spec does not exist”的归档提示。审核/实施可引用这两份变更，后续归档必须先处理基础规范，且归档仍需单独授权，不在本次工作范围内。

提案阶段执行 composer openspec:validate：72 项通过、0 项失败；本变更存在上述归档顺序提示。未修改业务代码，未执行应用测试、完整质量门禁或线上验收；这些是批准后实施交付的待办。


## Implementation evidence (2026-11-09)
用户批准后已实现：独立 GET /reimbursements/approvals 管理员待办；复用已有列表页面 approval=1 模式及详情审批，未增加页面注册、表结构、依赖或 Android 变更。候选记录按被指派、最新版本和 pending 限定，以 lazy(100) 分块遍历并复用 canDecide 判断，只保留当前页与准确总数。此方案避免复制审批规则，但耗时随个人被指派的未结单据积压增长；若积压显著增加，应改为持久化当前审批人索引并重新评估，而非修改既有 review 查询。

已执行：报销 Feature 15 项 / 164 断言；小程序全量 62 项；完整 composer quality:gate 通过（PHPUnit 479 通过、3 跳过；Vitest 314 通过；生产构建通过；OpenSpec 72 通过）。既有构建提示包含大于 500 kB 的 chunk，不属于此次变更。上线和真机实际审批尚未完成，不将本地验证作为发布证据。

微信开发者工具 2.02.2609250、skill 0.3.11：工作台、报销列表、报销详情三个修改过的 WXML 编译均返回 success=true。仅为模板编译，不等同真机交互验收。

## Release preparation (2026-11-09)
用户明确要求部署并在小程序完成审批测试，禁止操作他人已提交申请。发布基线采用最新 main f3a74d3（PR #60 已合并），仅移植审批增量，保留批量识别、草稿、开票日期、凭证来源及当前票据规则。服务端三个待更新文件部署前摘要与 main 一致；不执行数据迁移或全量目录同步。完整测试需先生成主站及独立报价构建；使用进程级 PHP 512 MB 配置，不修改生产配置。验收仅创建本次专用测试申请，保留原有申请和全局审批流程前后校验。
