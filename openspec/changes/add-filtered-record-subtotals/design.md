# Design

## 数据来源与权限

小计复用 `OntologyController` 已施加用户可见范围、搜索和高级筛选的记录查询。聚合查询从该查询克隆，不重新构造权限或筛选条件，避免口径漂移。排序不影响求和结果。

## 聚合规则

- 仅选择当前用户可见字段中 `type=number` 的字段。
- 普通字段从每条记录的 `payload[field]` 取值，每条记录最多计一次。
- `scope=item` 的数字字段遍历每条记录的 `payload.items`，每个明细值分别计入。
- 使用 PHP 有限数字判断；空值、非数字文本、`INF` 和 `NAN` 忽略，零值与负数保留。
- 使用数据库游标逐条读取匹配记录，避免一次性加载完整数据集。

## 响应与展示

服务端仅在长度感知分页器处于最后一页、命中记录数大于零且存在数字字段时返回 `subtotal`。该属性与 `records.data` 分离，因此不改变分页总数、页容量或真实记录。

前端把虚拟小计行追加到 AG Grid 当前数据末尾。小计行没有真实记录 ID，不可编辑、无操作按钮，并使用独立行样式。所有数字列显示对应总计；第一列同时展示“小计”标识。非最后一页收到 `subtotal=null`，不创建虚拟行。

## 非目标

- 不把真实最后一条记录替换或隐藏。
- 不汇总文本、只读文本、关系 ID、日期或选择字段。
- 不计算平均值、百分比派生值、去重值或跨对象关联金额。
- 不改变 CSV 导出内容。
