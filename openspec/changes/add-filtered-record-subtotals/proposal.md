# Change: 为筛选后的业务资料增加动态小计

## Why

业务资料表已经支持搜索、组合筛选、排序和分页，但用户无法在当前筛选口径下快速查看数字字段总量。手工导出或逐页计算容易遗漏，并且无法随筛选条件即时变化。

## What Changes

- 在筛选结果最后一页的真实记录之后追加一条只读“小计”行。
- 小计覆盖当前用户有权查看且命中当前搜索与筛选条件的全部记录，不受分页切片影响。
- 对元数据中类型明确为 `number` 的普通字段和明细字段分别逐值求和。
- 空值、非数字文本和非有限数值不计入；零值和负数按原值计入。
- 非最后一页、无命中记录或没有数字字段时不展示小计行。

## Impact

- 影响所有复用业务资料列表的对象类型。
- 不新增数据库字段或迁移，不修改记录、筛选、排序、分页、导出或权限契约。
- 每个末页列表请求最多增加一次读取筛选结果的流式聚合查询。
