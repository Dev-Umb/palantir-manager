## Why
小程序客户页缺少 Web 已有的快速新增客户和联系人入口；合同上传需要支持聊天文件和手机图片来源。

## What Changes
- 客户页新增客户表单，复用 /project-customers 原子保存客户和可选联系人，沿用管理员及业务员权限。
- 字段对齐现有快速新增：客户名称、地址、等级、备注、联系人姓名、电话。
- 保留聊天合同选择，补充相册/拍照；PDF 使用聊天文件入口，本地 PDF 可先发送文件传输助手。用户已确认聊天文件＋相册／拍照即可，不增加系统文件夹入口。
- 保持上传、AI 识别、人工核对、差异预览与归档流程。无数据库、权限、依赖或后台业务变更。
- 用户于 2026-11-14 明确要求开发并完成部署，授权本范围实现和发布；先合并 PR 后上传小程序。正式版本发布仍取决于微信审核。

## Impact
- mobile/wechat 客户入口、新增页、合同选择和 Node 测试。
- 不改现有客户搜索、分页、详情、项目编辑、审批通知及 Web。
