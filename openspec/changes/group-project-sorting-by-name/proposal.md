# Change: 项目主档按项目名称分组排序

## Why

项目主档当前无手动排序时按最近更新时间倒序；选择金额、日期等字段排序时，该字段成为第一排序键，导致同名项目分散在不同位置甚至不同分页中，不便于业务人员连续核对同一项目的不同批次、账户和补充记录。

## What Changes

- 项目主档无手动排序时默认按项目名称升序，并使用记录 ID 保证稳定顺序。
- 手动选择项目名称以外的排序字段时，项目名称升序为第一排序键，所选字段及方向为同名项目内第二排序键。
- 手动选择项目名称时，直接按用户选择的升序或降序排列。
- 项目页默认排序文案改为“默认（项目名称）”。

## Scope

### 必须改变

- 项目主档列表与项目导出采用同一名称分组排序。
- 相同完整项目名称的记录必须连续，并能跨分页保持稳定分组边界。

### 必须保持

- 筛选、搜索、分页、小计、权限及数据范围不变。
- 非项目对象继续沿用现有默认与手动排序规则。
- 用户选择字段的升降方向在同名项目组内生效。

### 禁止推断

- 不修剪、归一化或模糊合并项目名称。
- 不修改任何项目记录、客户记录或持久化字段。

## Validation

- PHPUnit 覆盖默认名称升序、手动字段组内排序、手动项目名称降序和非项目排序保留。
- Vitest 覆盖项目与非项目默认排序文案。
- 生产仅做只读 URL 与列表顺序核验，不编辑业务记录。
