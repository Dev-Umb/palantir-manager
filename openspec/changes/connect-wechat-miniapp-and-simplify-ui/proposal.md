## Why
现有微信小程序仅使用虚构本地数据，首页宣传区域占用主要空间，无法支撑真实项目查询。用户要求连接线上平台，先使用真实管理员账号，并将界面改为简单、直白的业务工具。

## What Changes
- 接入 https://palantir.umb.ink，首次由用户在小程序内输入现有管理员账号；权限由后端返回，不预置凭据或绕过认证。
- 复用 Laravel Session、CSRF、业务权限和项目可见范围；增加独立小程序 JSON 会话入口，避免网页登录重定向与微信 Cookie 行为耦合。现有网页和 Flutter 登录行为不变。
- 业务读取复用现有 Inertia 数据契约；新增和编辑复用原有服务端校验及写入路径，不另建业务数据库。
- 保留四个主导航，移除宣传大卡片、英文口号、重复页脚；突出搜索、状态、金额、待处理事项与明确操作。
- 默认真实数据模式，移除演示角色切换；保留模拟数据仅供隔离测试，不在登录失败时回退展示。
- 用户已确认线上首轮验收只读：允许真实登录和读取，不自动测试新增、编辑、标记已读、上传、AI调用或其他业务写入。

## Impact
- 小程序：/Users/umb/WeChatProjects/miniprogram-1，网络层、会话、页面、样式和测试。
- 后端：独立小程序会话路由/控制器、限流和测试；不改现有业务权限、持久化 schema 或依赖。
- 不把微信 openid 绑定、微信一键登录、自动管理员免登、支付、公开分享或发布纳入本次。
- 需要后台 request 合法域名配置及证书真机验证；不得以关闭域名/证书校验作为交付。
- 本提案等待用户审阅批准后实现；后端变更须先合并 PR，再部署，再做线上只读验收。
