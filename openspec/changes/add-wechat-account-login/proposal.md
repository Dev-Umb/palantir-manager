## Why
个人主体小程序需要微信身份登录，不依赖手机号权限。用户明确要求小程序不再提供密码登录入口，后台账号应能绑定微信。

## What Changes
- 小程序只展示微信登录；未绑定时引导输入从已登录平台后台获取的一次性绑定码，不自动注册。
- 后台个人账号设置提供绑定状态、生成短期一次性绑定码和解绑入口。绑定码绑定当前账号，不允许客户端指定任意用户。
- 小程序通过 wx.login 获取 code，服务端向微信校验后取得 AppID 范围内的 OpenID；结合一次性绑定码完成绑定并建立现有 Laravel 会话。
- 后台管理员用户管理展示绑定状态并允许具有 rbac.manage 权限的管理员确认解绑；不允许手工填写 OpenID 冒充微信绑定。
- 保留后台及其他客户端原有密码登录；小程序移除密码表单，但不删除现有共享会话接口。
- 不获取手机号，不新增头像昵称同步，不变更角色、业务数据和可见范围。

## Impact
- 新增微信绑定持久化及短期绑定码状态；新增微信登录、绑定、生成绑定码和解绑端点。
- 涉及后端身份认证、后台 Settings/Rbac 界面、小程序登录及我的页面和对应测试。
- AppSecret 仅经受控方式配置于服务端，不进入 Git、小程序包、日志、预览文件或 API 响应。
- 先完成提案审阅批准，再实施；后端测试及 PR 合并后才能部署。真实绑定由用户本人用手机完成，自动化不绑定开发工具微信至管理员账号。

## User setup
- 确认使用已有个人主体小程序 AppID。
- 在微信公众平台重置此前发在聊天中的 AppSecret，并通过受控服务器配置方式提供；不要求再次粘贴到聊天。
- 如微信服务端接口提示 IP 白名单限制，按实际服务器出口 IP 配置，不猜测 IP。
- 部署后登录后台生成绑定码，在本人手机小程序完成一次绑定，退出后验证微信登录。
