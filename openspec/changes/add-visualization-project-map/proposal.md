## Why

Web 首页需要直接进入可视化驾驶舱，减少标题和导航占用的展示空间，并以真实项目为基础展示公司业务的地域覆盖。

## 范围合同

- 必须改变：首页进入可视化大盘；移除大盘顶部标题和描述；提供桌面侧栏折叠及浏览器全屏开关；原公司回款卡片改为动态项目覆盖地图；回款扇形图与回款摘要整合到项目主档金额汇总。
- 必须保持：经营大盘及所有原有导航入口、全部金额和回款口径、图表及明细链接、认证权限、可见项目范围、移动端导航、密码提醒和业务数据。
- 允许隐藏：大盘标题描述；用户主动折叠后的桌面侧栏；全屏模式下的导航占位。
- 必须可见：菜单恢复及退出全屏按钮、数据范围和更新时间、回款金额及比例、山西文水鑫源昌和江苏宿迁晋武重工标定点、概略位置及覆盖动画说明、已定位和未定位数量。
- 禁止推断：不虚构项目或境外覆盖，不将客户总部当作项目地点，不把覆盖动画称为真实运输轨迹，不凭项目地名推断承接工厂，不回写推测坐标到业务主档。

## What Changes

首页导航到可视化大盘，经营大盘迁至独立稳定入口；检索原有首页和命名路由引用并逐项调整，保留登录回跳、专用账号分流和移动端行为。

标题区改为紧凑工具栏，承载范围、时间、业务明细、侧栏和全屏控制。菜单折叠仅在驾驶舱启用；退出浏览器全屏及不支持全屏时均能恢复操作。

原公司回款卡片改为项目覆盖地图。回款扇形图、比例、已回款和尚未回款金额、同源发生额及覆盖口径移入项目主档金额汇总，与原三项金额共同展示；两种财务统计口径保留各自说明，不混用分母。地图使用国内主要视野，真实境外项目存在时提供世界视野。地图提供工厂静态标记、概略项目点和流动弧线；弧线仅表示业务覆盖，工厂归属未知时不得绘制具有归属含义的连接。优先使用现有依赖或静态地图资产，不新增依赖。

读取当前用户可见的实际项目，只纳入可见关联合同具有合同/加工函附件或项目已确认加工函的记录，以明确地点字段、项目名称中的可识别地名及经核验合同原件建立可审查的显示层位置映射。城市级概略点位优先于省级点位；同地或约50公里近邻仅保留已回来合同金额合计最大的项目，金额未维护不得伪造为0，稳定按项目编号处理并列。财务图表不应用地图筛选。城市不确定但省份明确时采用省级概略位置；跨区域项目支持多地点；歧义或无法识别的项目计入未定位。标注位置依据和概略精度，任何未授权项目不参与点位或计数。

## Capability Preservation Map

| 原能力 | 新承载 |
| --- | --- |
| 首页经营大盘 | 独立经营大盘路由和原菜单项 |
| 可视化大盘入口 | 首页及原 /visualization 兼容入口 |
| 顶部范围、截止时间、明细 | 紧凑工具栏 |
| 回款环图、比例、金额、覆盖口径 | 项目主档金额汇总内保留摘要及环图，注明原同源回款口径 |
| 其余金额、业务员、欠款、阶段图表 | 原大盘内容保留 |
| 桌面导航及账户操作 | 展开侧栏，折叠时保留恢复按钮 |
| 移动导航、密码提醒 | 现有布局行为保留 |
| 项目权限及数据范围 | 同一 ProjectVisibility 范围内生成地图 |

## Capabilities

### New Capabilities
- `visualization-cockpit`: 首页驾驶舱、可恢复的沉浸展示与真实项目地域覆盖。

### Modified Capabilities
无。

## Impact

Web 路由、导航、驾驶舱布局、可视化数据构建及对应 PHPUnit/Vitest。无财务数据、权限或持久化 schema 变更，无真实物流追踪能力。当前本地数据库配置指向不存在的临时文件，实施前需获取可用的真实项目只读来源；尚未完成实际地域核验。

用户最新确认：项目点与工厂点不得扩散或脉冲，动态效果仅保留在线段上。

用户追加版式确认：顶部地图和金额汇总卡片减少空白，高度约为截图红框；保留底部统计与口径说明。

用户追加批准：地图滚轮缩放、拖动平移、双击复位；删除红圈标出的地图底部两句与金额汇总底部两句描述。图例、点位统计、金额、比例及其他卡片说明保持可见。

用户追加确认：项目点圆圈进一步缩小，工厂标定和命中区域保持；缩放行为一并发布。

用户追加确认：地图交互画布覆盖整张卡片，以卡片外边缘裁切；标题、视野切换和统计浮在地图上方；等比例地理与指针命中保持一致。

点位显示修正：禁止为了防重叠偏移坐标。全国与世界视野均采用相同经纬度对应的底图投影；近邻筛选保持原规则，重叠由缩放查看，不移动到其他行政区。
