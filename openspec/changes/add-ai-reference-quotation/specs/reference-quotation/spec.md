## ADDED Requirements

### Requirement: 对话式临时参考报价

系统 SHALL 提供独立的参考报价工作区，接受文本和图片，通过追问补齐参数，支持可选的平台项目关联，并显示可检查的参数与参考报价预览；不得引入审批或业务状态，不得回写合同和财务金额。

#### Scenario: 图片参数模糊

- **WHEN** 图片中的规格、数量或单位无法可靠识别
- **THEN** 系统 MUST 展示原资料和待确认字段并询问用户，不得推断该数值或生成含该未确认字段的总额

#### Scenario: 未匹配平台项目

- **WHEN** 用户报价的项目未在可见项目范围中明确匹配
- **THEN** 系统 MUST 允许独立填写项目与标段，不得强绑定相似项目

### Requirement: 价格来源与网价确认

系统 SHALL 优先采用用户提供的价格；历史报价及互联网网价仅作推荐，必须展示来源和适用口径，用户确认后才可用于计算；钢材网价 MUST 独立确认日期、市场、品种、规格、品牌、税口径和组合规则。

#### Scenario: 推荐价格尚未确认

- **WHEN** 历史价或网价推荐尚未获得用户确认
- **THEN** 系统 MUST 保留推荐内容和未确认提示，并阻止使用该价格计算或采纳结果

#### Scenario: 用户改变价格口径

- **WHEN** 用户改变网价、取价日期、材质规格、市场或计价方式
- **THEN** 系统 MUST 使相关确认失效并重新确认，不得沿用旧确认进行新计算

#### Scenario: 找不到指定网价

- **WHEN** 联网查询失败、需要登录或不存在指定日期和规格价格
- **THEN** 系统 MUST 明确说明并支持用户输入价格，不得悄悄改用其他市场或日期

### Requirement: 确定计算与单价报价

系统 SHALL 由确定规则计算参考金额，明确数量单位、单重/总重、税运范围及舍入规则。

#### Scenario: 已给总重量和套数

- **WHEN** 用户给出8套、总重量31.2吨和吨单价
- **THEN** 系统 MUST 按31.2吨乘吨单价计算，不得再次乘8套

#### Scenario: 未给重量

- **WHEN** 用户选择吨价报价但没有确定重量
- **THEN** 系统 MUST 支持只生成已确认的参考单价，总额显示未计算，不得把未知重量当零

### Requirement: 业务员采纳留档

系统 SHALL 在业务员明确采纳时保存独立归属及不可被后续工作区改动的参数、来源、价格、计算结果和文件快照，不得把采纳视为签约、审批或发给客户。

#### Scenario: 本人采纳参考报价

- **WHEN** 当前业务员确认报价名称并采纳已确认计算的结果
- **THEN** 系统 MUST 以服务端当前身份建立归属，保存快照并在本人档案中可查看和下载

#### Scenario: 修改后重新报价

- **WHEN** 业务员从已留档快照重新报价并调整参数或价格
- **THEN** 系统 MUST 创建独立工作区并重新确认价格，原快照及原文件 MUST 保持不变

#### Scenario: 他人访问档案

- **WHEN** 未获授权的用户查看、下载或复用另一业务员的报价档案
- **THEN** 系统 MUST 拒绝访问；该用户本人的档案查看与下载 MUST 继续可用，不得仅依靠前端列表过滤

#### Scenario: 留档写入失败

- **WHEN** 采纳留档请求未成功保存
- **THEN** 系统 MUST 保留工作区内容并提示重试，不得显示成功或新增虚假的档案记录
