# 财务发货工作台 M1

## Why
财务现以业务员、项目维护多种 Excel 发货台账。需要在业务资料基础上直接编辑明细、自动保存与小计，避免开票、收款、合计重复计吨。

## What Changes
- 必须改变：业务员 → 项目概况 → 发货单明细；单元格自动保存，末尾空白行，右键下方插行；Excel/CSV 预检、明细导入、来源追踪。
- 必须保持：原业务资料入口、数据范围、首次发货日期、合同及回款字段、已有功能和未提交改动。
- 允许隐藏：扩展计价原文折叠到来源信息。
- 必须可见：保存中/成功/失败、冲突、待订正、每单小计、项目累计、导入排除原因。
- 禁止推断：含糊的项目匹配、未确认的单位、空白日期或车号继承、退货冲减规则。
- 用户最新要求暂停业务资料数据打通：signed_weight、last_shipment_date 及全部已有业务数据不写入；吨数与日期仅在财务台账内统计。件台米保留但不计吨；开票收款小计排除。
- 用户于本聊天批准原型及本地开发、UI 走查、武华晓资料导入。当前为 apply 授权，非仅提案；最新授权尝试线上部署并只读核对已有项目；不允许修改线上已有业务数据，不授权含糊项目关联或归档。

## Impact
新增专用台账存储及导入记录，复用项目 ObjectRecord、ProjectVisibility、AuditLog、Layout。只有财务/管理员且具项目权限可以使用。仅在独立本地数据库验收；导入不覆盖线上资料。
