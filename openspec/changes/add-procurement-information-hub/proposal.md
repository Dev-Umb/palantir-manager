# Why
建立独立招采信息集散地，以公开证据和只读项目主档支持找标、历史价格研究和企业适配；由采集、分析、推荐、统筹审计四类 Agent 协作维护。

# What Changes
- 新增公告、详情、研究、关注、企业资料、来源及 Agent 管理页面。
- 新增独立 hub 数据表、来源适配与安全抓取、证据版本、任务和审计。
- 用户已明确批准此统一方案实施。共用登录；根据用户最新授权，仅只读当前账号可见项目主档的必要字段，禁止其他 ERP 业务查询及所有 ERP 写入。

# Capabilities
## New Capabilities
- `procurement-information-hub`: 独立公告、资料、分析及 Agent 协作。
## Modified Capabilities
- 无；仅添加导航入口与独立路由和调度，不改变 ERP 业务契约。

# Impact
新增独立表和后台队列任务，无依赖变更。已验证的中国化学、安徽建工来源自动初始化采集；其他候选来源保持停用，尊重已有人为停用。首页自动展示可核验的初筛推荐并后台生成审计后的深度分析，无企业配置前置条件。保留全部未提交工作。无需 ERP 数据迁移。
