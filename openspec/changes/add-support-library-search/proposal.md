# 支架组合检索共享模块

## Why

技术人员现用离线支架检索工具按高度段、跨距和组数查库算量，个人浏览器修改不能成为平台共享资料。需要保留当前demo页面与完整业务规则，在现有平台提供技术人员可维护的一套共享库。

用户2026-10-12请求先输出详细PRD、UI/UX、各模块入参出参、计算逻辑、开发计划、验收标准和测试用例，并确认“共享库，技术人员均可维护”。用户随后明确要求「严格按照这个开发计划来进行开发」，已授权 apply；本地实施不代表部署或归档授权。

## What Changes

- 独立支架组合检索单页，对齐demo的概览/库操作、输入与说明、结果、目录及内联编辑/导入预览。
- `engineering`和现有admin惯例获得模块view/manage/export；沿用平台登录、有效权限和限制型账号规则。
- 共享库不可变版本、原子保存/导入、冲突与幂等保护，保存后刷新查询；明确替换localStorage权威状态。
- 保留单柱、多段、多跨、多搭配、新旧组数语法、全网格面数、接头螺栓、孔位/型号分列、已计和完整重量语义。
- 保留XLSX预览确认、页面三类数据编辑、单表明细导出、两表库交换、含说明的空白模板和离线HTML快照。
- 显式改进：页面编辑也约束自然键唯一；平台响应乱序/版本变化使旧结果失效；离线快照标明不会自动同步共享库。

## Scope Contract

必须改变：独立入口、技术授权、共享持久化、服务端规则与事务。
必须保持：当前demo全部可见有效能力、数值口径、来源追踪及其他模块数据/接口/权限。
允许隐藏：未触发的编辑/预览、无权入口；不恢复已退役CSV和旧结果页签。
必须可见：范围、缺项、未知值、共享版本、保存/冲突/导出状态。
禁止推断：结构验算、未收录搭配、未知重量、跨用途适配、附件或组间构件用量。

## Impact

新增capability `support-library`。建议加法schema为共享库活动指针和不可变JSON版本，限定共享接点为导航、权限目录与模块路由。无项目/合同/财务/报价/采购/工日簿业务改动，无AI写入或新部署栈；不改变依赖。
