## Data lineage

公司回款图复用线上 CollectionProgress 对授权项目的 summarize 规则，与原经营大盘相同，不修改其缺失值约定，不使用合同额兜底。无有效正分母时显示空态，超额或负值保留数值而省略扇区。

项目卡片、业务员金额分布、欠款项目图读取授权 project 的 occurred_amount、paid_amount、unpaid_amount，使用线上 business_owner_user_id 的业务员账号归属分组，批量读取账号名称。金额单位元，前端转换万元。未维护经理单列业务员未维护。每个业务员占比指标有独立有效覆盖和分母，颜色在三个图中保持一致。欠款金额不重新推导为发生减回款；三个原始金额为独立条形。缺失金额显示 —，零仍是有效数据。负数原记录计入真实汇总净额并披露数量；业务员汇总净额均非负且总额大于零时正常绘图，否则省略扇区。类别多时完整图例可滚动读取。

欠款图默认按正欠款金额降序前五，同额以 ID 稳定排序。时间表仅纳入有效正欠款、有效 YYYY-MM-DD 最后回款日期且不晚于今天的项目；按日历天数降序、同额以 ID 排序。用户已明确无日期不统计，不使用创建时间。排除数量可见，时间表保留全部合格项目，通过固定高度内部滚动。颜色按从久到近的排序增强，不另行定义逾期等级。

线上当前项目总体状态为投标中、已中标、已拿到加工函、合同签署、已完成。阶段图沿用原驾驶舱前四种活跃状态，已完成或未维护状态单列摘要，不制造已移除的 stage 字段。
