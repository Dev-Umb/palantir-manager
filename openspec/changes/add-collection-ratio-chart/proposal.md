## Why

用户已批准独立“可视化大盘”及确认 UI，希望直接查看公司回款、业务员金额占比、重点欠款项目、未回款时长和项目阶段。原经营大盘保留。

## What Changes

- 新增独立只读页面和并列导航入口，不修改默认首页。
- 公司回款环形图与项目主档三个金额卡片。
- 三个业务员环形图分别展示已发生、欠款、已回款金额占比，每个指标有独立分母、完整图例和金额。
- 欠款项目回款情况：按有效正欠款金额降序默认前五，分别显示已发生、已回款、欠款三个原始金额。
- 项目未回款时间排行表：只纳入欠款大于零且最后回款日期有效的项目，以该日期至今天的日历天数降序排列，越久越醒目；缺失、无效或未来日期不回退创建日期，不纳入排行并提示排除数量。
- 项目阶段环形图只包含进行中、预警项目，其余状态以数字摘要显示。

## Scope Contract

- 必须改变：新增页面、导航和确认图中的图表与唯一时间排行表。
- 必须保持：原经营大盘、业务表格、操作、权限和项目可见范围、业务数据与已有计算规则。
- 允许隐藏：新页面不直接展示其他明细表；无来源权限的面板及数据在服务端省略；异常金额只显示真实数值和解释，省略误导扇区。
- 必须可见：范围、时点、单位、金额、占比、覆盖、空态与异常解释、原有明细访问入口。
- 禁止推断：不同来源金额凑成闭合整体、缺失等于零、累计字段倒推历史趋势、缺失回款日期替代为创建日期、颜色代表未经批准的逾期规则。

## Capability Preservation Map

| 原能力 | 实施后的载体 |
| --- | --- |
| 经营大盘所有已有功能 | 原路由和页面保持，新页可返回 |
| 总回款比例 | 新页公司环形图使用同组有效财务台账，原首页不改 |
| 项目主档金额及业务员金额 | 新页直接读取同字段，原项目页面保留 |
| 项目明细、编辑操作 | 查看业务明细入口及项目条目链接，目标路由仍执行授权 |
| 项目阶段与状态 | 新页只读聚合，原项目字段和状态不改 |
| 数据权限 | 既有对象权限及 ProjectVisibility 服务端过滤 |

## Impact

新增只读路由、聚合 Action、Inertia 页面、独立样式、导航和回归测试，不新增依赖、迁移、持久化汇总或后台写入。当前工作区是旧版 Dashboard，采用其真实 Layout 与对象字段，不以旧版替换截图对应线上页面。实施仅证明当前工作区本地行为。

## Approval and Evidence Boundary

用户已批准确认 UI 并明确最后回款日期口径。实际渲染截图使用演示数据，应用读取真实对象数据。本地测试、生产构建和质量门禁完成；未提交、部署、在线验收或归档。
