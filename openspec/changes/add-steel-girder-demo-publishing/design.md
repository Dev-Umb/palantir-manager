## Decisions
沿用钢箱梁 view + manage 权限管理发布。每次部署分配至少 128 位安全随机标识，分享路径为 /d/{id}/index.html。演示域名使用 site.umb.ink。优先选择根目录或唯一外层目录下的 index.html；没有 index.html 且仅有一个 HTML 时，以该文件为入口，分享其 URL 编码后的原始路径。多个候选入口时提示整理压缩包。按包内相对路径上传，保留文件名、层级并设置正确 MIME。直接引用入口对象，避免依赖私有桶目录首页。
使用独立 HTTPS 演示域名和专用私有桶，CDN 签名只读回源。域名隔离工作台会话，禁止目录枚举。MP4 支持 Range，视频由 CDN 传输。无需服务端执行包内代码。
解压前及流式读取时限制文件数、实际字节数，拒绝越界路径、链接、重复路径和损坏包。资源全部就绪后最后写入入口并显示链接。失败清理本次对象。撤下先移除源站对象，再刷新该演示 CDN 缓存，完成前显示处理中；失败可重试。

## Rollback
关闭发布入口，保留记录；按发布标识独立撤下。已下载到访客设备的副本无法远程收回。
